# История изменений

## 2.0.0-beta.1

- Основная установка перенесена в BusyBox sh на OpenWrt, Windows frontend только передаёт проект по SSH.
- Определение архитектуры, APK/IPK, обычный/компактный Xray по фактическому месту, отдельные настройки RAM и zram.
- Потоковая выборка нужных пакетов из ZIP, SHA-256 по GitHub release metadata, проверка кеша и UPX.
- Одиночные ссылки и HTTPS-подписки через импортёр PassWall2, выбор узлов и сохраняемые исключения.
- Сохранение настроек при обновлении, восстановление конфигурации/старого Xray при ошибке; без отката версий пакетов.
- Офлайн-проверки матрицы архитектур, импорта и сбоев; физические устройства в новой реализации ещё не проверены.

## 1.0.0

Первый публичный релиз.

- установка и обновление PassWall2/Xray для Cudy WR3000H/S и x86_64;
- UPX и zram для Cudy;
- импорт подписки, балансировщик и готовые правила маршрутизации;
- защита от ошибочного обновления или повторной чистой установки;
- бэкапы, диагностика и безопасная очистка старых прокси-компонентов;
- запуск из PowerShell одной командой.
