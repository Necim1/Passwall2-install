# PassWall2 Router Setup

Переход на бету — по желанию, автоматической замены нет. Версия 1.0.0 и её инструкции ниже сохранены; ветка `main` продолжает содержать прежний установщик. Проверки беты в CI не заменяют испытания на реальном роутере.

Интерактивный установщик PassWall2 и Xray для роутеров с OpenWrt 25.12.5 и новее. Управление выполняется через меню PowerShell: установщик скачивает актуальные пакеты, проверяет совместимость устройства, создаёт резервную копию и настраивает сервисы без ручной сборки конфигурации.

Текущая версия: **1.0.0**.

## Возможности

- чистая установка PassWall2 и Xray;
- безопасное обновление существующей установки;
- импорт и ежедневное обновление подписки;
- готовые правила маршрутизации для популярных сервисов;
- балансировка Xray-узлов по минимальному пингу;
- автоматические резервные копии перед изменениями;
- диагностика PassWall2, Xray, nftables и zram;
- очистка Podkop, Forkop, старого PassWall и лишних прокси-компонентов;
- защита от запуска обновления на чистом или повреждённом роутере.

Фильтрация серверов подписки по названию не применяется. Все совместимые Xray-узлы добавляются в балансировщик, поэтому установщик подходит для разных провайдеров.

## Поддерживаемые платформы

| Профиль | Архитектура | Особенности |
| --- | --- | --- |
| Cudy WR3000H / WR3000S | `aarch64_cortex-a53` | Xray сжимается через UPX на компьютере, на роутере настраивается zram 256 МБ |
| x86_64 | `x86_64` | Обычный пакет Xray без UPX и дополнительного zram |

Профиль выбирается вручную. Перед любыми изменениями установщик сверяет выбранный профиль с моделью роутера, архитектурой и версией OpenWrt.

## Требования

- Windows 10 или Windows 11;
- PowerShell 5.1 или PowerShell 7;
- установленный Windows OpenSSH Client (`ssh`, `scp`, `ssh-keygen`);
- OpenWrt 25.12.5 или новее с пакетным менеджером `apk`;
- root-доступ к роутеру по SSH;
- доступ в интернет с компьютера и роутера.

OpenWrt 24.10 и более старые версии не поддерживаются.

## Быстрый запуск

Откройте PowerShell и выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force; irm "https://raw.githubusercontent.com/Necim1/Passwall2-install/main/bootstrap.ps1?nonce=$([guid]::NewGuid().ToString('N'))" | iex
```

Разрешение выполнения сценариев действует только в текущем окне PowerShell. Bootstrap загрузит актуальную версию проекта в `%LOCALAPPDATA%\PassWall2RouterSetup\app` и запустит меню. Повторное выполнение команды обновит локальную копию.

Для запуска уже скачанного проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup.ps1
```

Пароль root запрашивается один раз. На время сеанса создаётся отдельный SSH-ключ, который удаляется с компьютера и роутера при завершении работы.

## Главное меню

1. Чистая установка PassWall2 и Xray.
2. Обновление существующих PassWall2 и Xray.
3. Добавление или замена подписки.
4. Повторное применение списков маршрутизации.
5. Проверка состояния.
6. Создание резервной копии настроек.
7. Очистка старых и конфликтующих прокси-компонентов.

## Маршрутизация

В комплект входит обезличенный шаблон с отдельными правилами для Discord, Telegram, Google, YouTube/WebRTC, Meta, TikTok, Twitter, Cloudflare и других сервисов.

Узлы подписки объединяются в балансировщик `leastPing`. Проверка доступности выполняется каждые 30 секунд. Существующие подписки и физические узлы сохраняются при повторном применении маршрутизации.

## Установка и обновление

Перед изменением пакетов создаётся `sysupgrade`-бэкап и рассчитывается SHA-256. При чистой установке проверяется наличие PassWall2, Podkop, Forkop и их остатков. Обнаруженные конфликты необходимо удалить через пункт очистки.

Обновление разрешается только при наличии полноценной установки: APK PassWall2, init-скрипта, UCI-конфигурации и рабочего `/usr/bin/xray`. Подписки, узлы и правила маршрутизации во время обычного обновления не заменяются.

Если последний релиз PassWall2 ещё не содержит полный комплект APK для выбранной архитектуры, автоматически используется предыдущий полный релиз.

## Очистка

Доступны два режима:

- удаление конфликтующих компонентов с сохранением PassWall2 и его Xray;
- полное удаление прокси-стека, включая PassWall2, подписки, узлы и маршрутизацию.

Перед удалением отображаются найденные пакеты, оставшиеся файлы и результат `apk del --simulate`. После создания бэкапа операция требует ручного ввода `DELETE`. Принудительное удаление пакетов не используется.

## Резервные копии

Бэкапы на компьютере сохраняются в каталоге `PassWall2RouterSetup\backups` внутри LocalAppData.

Локальные копии конфигурации PassWall2 и Xray на роутере сохраняются в `/root/pwsetup-backups/`.

Резервные копии могут содержать пароли, ключи OpenVPN, адреса серверов и ссылки подписок. Не публикуйте их в репозитории и не прикладывайте к отчётам об ошибках.

## Проверка

Сценарий установки проверен на Cudy WR3000H/S с OpenWrt 25.12. Профиль x86_64 использует тот же основной процесс установки без UPX и zram.

При создании Issue удалите из диагностического вывода адрес роутера, внешний IP, ссылки подписок, UUID и ключи.
