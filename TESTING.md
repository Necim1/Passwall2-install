# Проверка 2.0.0-beta.1

Дата: 2026-11-12. Локальная среда: Windows, Git for Windows `sh`, Python 3.13, Windows PowerShell 5.1. Дополнительно выполнен GitHub Actions на Linux с BusyBox ash и настоящий bsdtar.

В [GitHub Actions](https://github.com/Necim1/Passwall2-install/actions/runs/43114462655) пройдены все **23 теста без пропусков**:

- выбор полного релиза для 13 архитектур × APK/IPK, старые/новые названия архивов, пропуск непроверяемого релиза;
- профили RAM, выбор full/compact, недостаток flash, учёт замены старых файлов;
- проверка SHA-256, повторная проверка кеша, отказ при повреждённой загрузке;
- выбор ровно нужных пакетов настоящим bsdtar из ZIP, потоковая распаковка с проверкой SHA-256 и отказ при неверной сумме потока;
- передача VLESS/VMess/Trojan/SS-ссылок без изменения параметров импортёру, HTTPS-подписка, скрытие URL в выводе;
- отказ при нескольких строках/неподдержанном вводе, восстановление после импорта без узлов;
- сохранение исключений после смены ID, отказ при ошибке фильтра;
- восстановление при ошибке пакетного менеджера, кеширование DNS до удаления и попытка возврата из кеша;
- сохранение выключенного прокси при ежедневном обновлении;
- передача параметров памяти и аргументов runtime;
- запуск нового zram один раз, сохранение существующего zram, отказ UPX при недостатке памяти подготовки.

Также пройдены `sh -n`, `shellcheck -S error`, проверка синтаксиса PowerShell 5.1 и прежние тесты плана очистки. Проверен коммит `92551041746bfc8fc1e7817a792d59878d24f9d6`; изменения после него относятся к документации.

При локальном запуске на Windows тест ZIP из потока пропускается из-за ограничения встроенного Windows tar. На Linux этот тест успешно выполнен. Первый запуск CI выявил повторную подстановку `/tmp` в изоляции тестов; обвязка исправлена и весь набор пройден повторно.

OpenWrt-команды и импортёр в поведенческих тестах подменяются. Поэтому тесты подтверждают управление установкой и передачу данных, но не доказывают реальную установку APK/IPK на прошивку, разбор конкретной подписки штатным Lua, доступность VPN-сервера, Wi-Fi, скорость, работу после перезагрузки или устойчивость под нагрузкой. Физические Cudy/Raspberry Pi/MIPS и настоящий Xray-сервер для этой новой версии не использовались. До стабильного релиза нужны установка на тестовый OpenWrt и нагрузочные проверки.
